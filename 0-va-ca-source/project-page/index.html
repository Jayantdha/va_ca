How it works

1. VerifiedBusinesses sign up with a mobile OTP and GSTIN. An admin approves them.
2. LikeBusinesses like influencers. Influencers see nothing yet.
3. Pay, then waitAn influencer pays once. The server starts a 7-day timer.
4. Reveal and chatAfter 7 days likes are revealed. A like back opens a chat.

PaymentsOnly a signed webhook can mark "paid". Screenshots and app edits count for nothing.
The 7-day holdServer clock only. Before the date, the API returns no likes, not even a count.
PrivacyEvery chat, photo and payment is checked per user. Consent, export and delete are built in.
Accounts15-minute tokens, rotating refresh tokens, stolen-token detection, log out everywhere.

Honest limits

Built with AI assistance (Claude). The SMS, CAPTCHA and payment adapters are written to the providers' documented formats but have not been tested against the live services. There are no real users or payments. It has not had an independent security review.
